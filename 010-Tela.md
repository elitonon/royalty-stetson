## CRIAÇÃO DA TELA

* Crie um formulário onde o usuario possa digitar, nos campos abaixo, informações que serão usadas para extrair dados do banco de dados Oracle: 

* O formulário deve ter, após a criação dos campos abaixo, um botão 'GERAR', um botão 'IMPRIMIR' e uma área abaixo deles para mostrar os resultados dos dados 
extraídos do banco oracle, com base nas informações que o usuário digitou:
Campo 'codigo empresa' no formato numérico com 3 caractares e com a descrição do campo sendo 'CÓDIGO DA EMPRESA: ',
Campo 'data inicial', no formato de data dd/mm/yyyy e com a descrição do campo sendo 'DATA INICIAL DO FATURAMENTO: ',
Campo 'data final', no formato de data dd/mm/yyyy e com a descrição do campo sendo 'DATA FINAL DO FATURAMENTO: ',
Campo 'linha produto' no formato numérico com 2 caractares e com a descrição do campo sendo 'LINHA DE PRODUTO: '.

* Nos próximos arquivos .md deste projeto, ao solicitar que selecione as informações dos campos das tabelas, mantenha as peculiaridades 
de cada campo conforme sua criação na tebela do banco de Dados Oracle.

* Após o usuário preencher os campos do formulário e teclar ENTER ou clicar no botão 'GERAR', executar, pela ordem, os arquivos .md deste projeto.
