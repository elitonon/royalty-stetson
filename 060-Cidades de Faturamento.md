## Seleção de Dados das Cidades de Faturamento
* Selecione os seguintes campos da tabela basi_160 do banco de dados Oracle para cada registro selecionado no arquivo '050-Clientes de Faturamento.md':
	                     'basi_160.cidade',
	                     'basi_160.estado',
	                     'basi_160.ddd'
quando a seleção das informações da tabela basi_160 obeceder o seguinte critério:
                             'basi_160.cidade' for = ao campo da tabela 'pedi_010.cod_cidade'  do arquivo '050-Clientes de Faturamento.md'.
